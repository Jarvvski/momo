# Security policy

## Reporting a vulnerability

Do not open a public issue. Use GitHub's private vulnerability reporting instead: [Security](https://github.com/Jarvvski/momo/security) → **Advisories** → **Report a vulnerability**. That opens a private thread only the maintainer can see.

Include the momo version (`momo --version`), your OS and architecture, and the smallest reproduction you can manage. If you already have a fix in mind, say so.

## What to expect

momo is maintained by one person in their spare time, so there is no formal SLA. Expect an acknowledgement within about a week, and then either a fix or an explanation of why the report is not a vulnerability. Reporters are credited in the release notes unless they ask not to be.

## Supported versions

Only the latest release is supported. There are no backports — upgrade to the newest release and the fix is there.
